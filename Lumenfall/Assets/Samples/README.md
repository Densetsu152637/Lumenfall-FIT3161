# Samples

Store tutorial, demonstration, and starter-template content here. Sample content must be
safe to remove without breaking the production game.

Before production code depends on a sample asset, move or recreate the required asset in
`Assets/_Project`, preserve its `.meta` file where references must survive, and update all
serialized references. Imported vendor demo scenes can remain with their package under
`Assets/ThirdParty`.

Do not add production scenes, runtime systems, or final art here.
