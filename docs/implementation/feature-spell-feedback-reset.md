## Implemented behavior and API

- `SpellCaster.TryCast` returns `SpellCastFeedback`; `Cast` retains its bool signature. `CastFeedback` is `Action<SpellCastFeedback>` with `Spell`, `TargetId`, `Outcome`, `Changed` and player-facing `Message`. `CastCompleted` now fires exactly once for every attempted cast, including rejected attempts, with changed=false on rejection. Consumers must filter Changed/Outcome rather than assuming the event means success.
- Outcomes are Applied, LockedSpell, NoTarget, UnknownTarget, OutOfRange, IncompatibleTarget, InputBlocked, WorldUnavailable, CasterUnavailable, MovementBlocked and NoChange. Both input and direct calls enforce progression unlock, overlays/pause, ready map, live target, configured caster grid position, Manhattan distance to target footprint and authored spell compatibility. Default range remains two cells. Input prefers a valid target, then a nearby spell-compatible object for explicit incompatibility feedback; wide background footprints cannot shadow targets.
- Authored spell names (ampere/weave/gravitate/rotara/glaciate/vis/lost-echoes, enum spelling, or spell:EnumName) take precedence over categories. Supported categories include power-source/relic, circuit/weave-with:, movable/slidable, rotatable/mechanism, orientation and hidden. Untagged targets reject. Existing designer spell allow-list still constrains progression-unlocked spells. Tests now supply real grid-positioned casters and synthetic spell tags where they exercise multiple spells.
- SetProperty compares mutable snapshots; repeated Vis/reveal/frozen-at-goal casts report meaningful no-op. Gravitate blocked movement reports MovementBlocked. Glaciate may apply the initial freeze even when sliding is blocked, then report blocked on a subsequent attempt. Lost Echoes reveals only the selected local target.
- `WorldStateService.GetObjectFeedback`, `GetTargetFeedback` and `ObjectFeedbackChanged` (`Action<WorldObjectFeedback>`) expose Idle/Valid/Invalid/Solved/Restored. Solved derives from existing live map target evaluation, never a new quest-completion flag; restored objects also carry IsSolved. Invalid targeting overrides solved preview so rejection remains visible. The existing SpellCaster HUD shows outcome text and target status plus a nearby reset action. No new settings overlay or completion authority was introduced.
- `ResetPuzzle(puzzleId)` resets only that target's declared objectIds to the first registered authored mutable state. Required cable endpoints outside objectIds keep their state. Incident cables/strengths, effects keyed by exact object identity, registered legacy effect prefixes and selected puzzle progress are cleared. Other objects, other puzzle progress, unrelated cables/effects and archived maps remain intact. GameEventRuntime quest status, completion event history, rewards and unlock flags are untouched.
- Reset preflights every required object/baseline and complete authored footprint against GridWorld bounds, blockers, movers and reservations, excluding only selected object obstacles during the check and restoring their registrations in finally. Failure changes no object/progress/feedback state. IsReady=false suppresses monitors throughout reset; success publishes one final StateChanged and then PuzzleResetCompleted (`Action<string>`). Players must clear occupied authored cells before retrying. Headless null-view snapshots remain resettable when no grid is present; live objects require a grid.
- Baselines are runtime authored copies, separate from save data, retained across cached prefab re-enables and ResetAllState. Registration uses those copies so a new game cannot inherit a cached rotated/moved transform. Current/archived per-puzzle progress persists through the existing spell-world-state provider as an additive optional field; old saves default to empty progress. Restore applies only mutable cell/elevation/rotation/power/frozen/reveal/aligned state, retaining authored IDs/maps/footprint/spell tags/compatibility. Snapshot tags are defensive copies.
- The inherited five-relic board registers supplemental target quest.stella.first-light.board; generic reset restores all five. New board effects use stable IDs, while registered stella-relic:1: through :5: aliases clear queued effects from older saves. Its completion method now explicitly guards IsReady; board input, hints, teaching and durable completion otherwise remain inherited.
